# Annual Teacher Review

Annual Review Development Plan form in three stages:

1. Goals and Action plans (teacher)
2. Progress review (teacher)
3. Final review (Head Teacher only)

Open `index.html` in a browser, or use the GitHub Pages link.

## Submitting plans

Teachers submit Step 1 to a SharePoint list through Power Automate. See [SETUP-SHAREPOINT.md](SETUP-SHAREPOINT.md) to set it up.
